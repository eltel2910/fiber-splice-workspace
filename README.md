# Fiber Splice Workspace

A browser-based fiber splice diagram editor for creating cable trunks, equipment/end points, splice connections, patch cables, legends, and printable exports.

## Run locally

Open `index.html` in a modern web browser.

## Publish with GitHub Pages

1. Create a GitHub repository for this project.
2. Upload `index.html` and this `README.md`.
3. Enable GitHub Pages from the repository’s **Settings → Pages**.
4. Select the `main` branch and the root folder.

## Notes

- Projects are saved in the browser’s local storage.
- No server, database, or login is required.
- Saved projects are local to the browser and device where they were created.
